## Mainnet (needed for the mainnet round trip)

| Field | Value |
|---|---|
| Network | Bitcoin Cash mainnet |
| Address | `bitcoincash:qqxpyg7vz2xkcmd3pkuw3jpjs2gehsmh3ypxkxvjnm` |
| Asset | BCH |
| Amount | 50,000 satoshis (0.0005 BCH) |
| Template | `833cf84d9673303502e916f0a305753c4ada691d0e2c106ec4afec717aa4dd29` (the address is derived from this template id; editing the template changes it) |

Why: one plain coin of this size pays the whole lifecycle. fundMint locks 6,000 sats in the mint covenant, each of four
releases needs one 5,000 sat fee coin (the release pays out on it), and every transaction leaves about 200 to 1,200 sats to miners.
Expected spend is about 27,000 sats; the rest stays in the fund wallet as change.
Everything left is recoverable: the vault ends at its last release and the sweep action returns plain coins.

Then run: `node --import ./lib/no-native.mjs --env-file=.env scripts/lifecycle.mjs mainnet`.
